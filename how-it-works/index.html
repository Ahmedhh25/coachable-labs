How it works

Four steps from the first form to the first session, then a set arc that ends on a date you know before you start.

  1. You tell us what is going on

    A short form. Write it properly — we read it before we speak, so the call is not spent on background. Nothing about sending it commits you to anything.

  2. A thirty-minute call

    We work out where you are trying to get to and whether this is the right instrument for it. If it isn't, we say so on that call and point you somewhere better.

  3. A fuller assessment before session one

    A longer look across the seven sectors we work in, filled in by you and read by your coach beforehand. It is why the first session starts on the actual problem rather than on your history. The seven sectors are set out here.

  4. The engagement runs, and then it ends

    Six sessions for the individual track, four for marriage and family, across a set arc with phases and a stated end date. There is work between them.

What the arc looks like

Sessions run roughly every two weeks. That spacing is deliberate: it is long enough to try something and short enough that you have not lost the thread.

The arc is sequenced rather than being a list of topics worked through in whatever order they come up. It opens on purpose, because everything after it is judged against that. Accountability is set up early instead of being saved for the end — a purpose nobody is holding you to does not survive contact with a full calendar. The later sessions work outward from there into health, money and the people around you, and the last one is spent making sure what you have built runs without us.

The end date is agreed before the first session. It does not move because things are going well.

What is expected of you

  • There is work between sessions, and it is the part that makes the difference.
  • The feedback is direct. There are no affirmations here.
  • You have to be willing to say the actual version, not the one you would give a colleague.
  • Turn up. Six sessions is not many, and each missed one costs a sixth of the arc.

Confidentiality

This is private-pay. There is no insurance claim, which means no diagnosis and no documentation trail. There is no file with your name on it anywhere, and nothing you say in a session is repeated outside it.

What it costs

$500 – $1,500 for the engagement

The range is that wide because scope is set after the first conversation, and the scope is not the same for everyone. Nothing is charged before that conversation.

For context: executive coaching nationally runs $300 to $500 an hour.
